What you get

Two platforms, one schema

Scrape Eventbrite events and run a Luma event scraper in the same job. Times, venue, organizer, and prices share the same field names.

Search or paste URLs

Use a city and keyword, an Eventbrite category, a Luma category, or paste event, organizer, calendar, and search URLs.

Honest location data

Local and UTC times with an IANA timezone, plus coordinates when the venue is public. Hidden Luma addresses stay null, not an approximate point.

Filters and monitoring

Date range, free-only, keyword filters, and “only new events since the last run.” Skipped and duplicate events are not charged.

Who it is for

Event lead generation

Collect organizer names and public profile URLs for events in your niche, then export Eventbrite events to CSV or JSON for outreach lists.

Tech event monitoring

Watch AI, startup, and developer events in a city on Eventbrite and Luma. Schedule a daily run that returns only newly listed events.

Market research

See how many events, what ticket prices, and which formats appear in a city or category over a date range.

Calendars and city guides

Feed a weekly “what’s on” digest, a map, or an app with structured event data, including coordinates when they are public.

Run it from your code

Python, Node.js, and cURL examples with the real input fields are in the GitHub tutorial. Keep your Apify API token in an environment variable.

from apify_client import ApifyClient
import os

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("hiringdata/eventbrite-luma-events-scraper").call(run_input={
    "locations": ["San Francisco", "London"],
    "keywords": ["AI"],
    "platforms": ["eventbrite", "luma"],
    "startDate": "today",
    "endDate": "+30 days",
})
